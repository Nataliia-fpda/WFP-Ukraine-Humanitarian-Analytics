# WFP-Ukraine-Humanitarian-Analytics
Power BI dashboard analyzing World Food Programme humanitarian assistance in Ukraine, focusing on the number of beneficiaries assisted and cash based transfers provided during 2022–2025.

## Dashboard Preview:

01.Overview_2022-2025.png 

## Data

- Source: https://www.wfp.org/publications/annual-country-reports-ukraine (accessed Nov 2026)
- Data extracted from .pdf Summary Tables Annexes, cleaned and transformed in Power Query
   
## Project Objectives:

- Analyze the number of people reached by WFP assistance and the volume of cash based assistance provided
- Compare annual actual and planned humanitarian assistance indicators
- Identify trends and changes in assistance delivery during 2022–2025
- Present key humanitarian performance indicators through interactive visualizations

## Key Metrics:

- Number of Beneficiaries assisted — number of people who received humanitarian assistance
- Cash Based Transfers — total amount of financial assistance provided to beneficiaries

 ## Key Indicators:

- Deviation of Actuals from Planned.
- Plan Execution, %.    
- Year-over-Year (YoY) trend.

 ## Tools & Technologies:

    Microsoft Power BI
    DAX (Data Analysis Expressions)
    Power Query
    Data Visualization
